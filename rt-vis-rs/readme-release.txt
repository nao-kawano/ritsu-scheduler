Ritsu Visualizer
==================================================

Ritsu Visualizer is an interactive visualization and schedule design tool for Ritsu Scheduler.

■ How to Run

Double-click "rt-vis.exe" to launch the application.

■ Operating Modes

1. Create Mode
   Design, edit, and simulate schedule configurations (config.toml) from scratch.
2. Analyze Mode
   Load and visualize runtime execution logs (rt-server.log) to analyze scheduled vs. actual behavior.

■ Features

- Create Mode:
  - Create, edit, load, and save schedule configuration files (config.toml).
  - Drag-and-drop schedule editing with real-time dependency and timing validation.
  - Simulate ideal timeline execution and concurrent process load metrics.
- Analyze Mode:
  - Load and inspect Ritsu Server execution log files.
  - Overlay planned schedules against actual execution timelines (normal, overrun, skip).
  - Visualize instant scheduling events (Ready, Overrun, Skip, Late, Error) with diamond markers.
  - Track server cycle jitter and concurrent running process metrics with interactive tooltips.

■ Log Files (for Analyze Mode)

Ritsu Visualizer accepts log files generated by Ritsu Server (e.g., "rt-server.log").
The server automatically embeds configuration metadata (<CONFIG>) at startup alongside runtime state transitions (<STAT>), allowing the visualizer to reconstruct and overlay both the intended schedule and actual execution directly from a single log file.
